# nrachapa.github.io

Personal portfolio website showcasing professional experience, projects, research, and certifications.

## Overview

A modern, responsive portfolio website built with vanilla HTML, CSS, and a bento-grid layout design. Features include interactive modals for document previews, smooth animations, and a clean aesthetic with a warm color palette.

## Features

- **Bento Grid Layout**: Modern card-based design that adapts to different screen sizes
- **Interactive PDF Previews**: In-browser preview modals for resume and research papers
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Hover effects and transitions for enhanced user experience
- **Sections Include**:
  - Profile with skills tags
  - About me
  - Contact links (Email, LinkedIn, GitHub)
  - Resume preview and download
  - Professional experiences
  - Personal projects
  - Certifications
  - Research publications

## Tech Stack

- HTML5
- CSS3 (Custom properties, Grid, Flexbox)
- Google Fonts (Playfair Display, Montserrat)
